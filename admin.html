How do I get a token? (one-time, ~2 min)
1. Open github.com/settings/personal-access-tokens/new (Fine-grained token).
2. Token name: anything (e.g. “PMP admin”). Expiration: your choice.
3. Repository access → “Only select repositories” → pick montassarsallami122-spec.github.io.
4. Permissions → Repository permissions → Contents → Read and write.
5. Click Generate token, copy it, and paste it above.
The token is saved only in this browser (localStorage). It is never uploaded to the site.
⚠️ Treat the token like a password. Anyone who has it can edit your repo. Use a fine-grained token limited to this one repo, as above.
